# Contributing to Cartan

Thanks for your interest in Cartan.

## Before you contribute

- All contributions require signing the Contributor License Agreement (CLA). The CLA Assistant bot will ask you to sign on your first pull request. Pull requests without a signed CLA will not be merged.
- For anything larger than a small fix, open an issue first to discuss it.

## Pull requests

- Follow the existing code style (`.clang-format`).
- Add tests for new functionality; all tests must pass (`ctest`).
- Add the license header to every new source file:

  ```cpp
  // Copyright (C) 2026 João Gabriel Abrahão Franco
  // SPDX-License-Identifier: AGPL-3.0-or-later
  // Additional terms apply under AGPL-3.0 Section 7(b); see NOTICE.txt.
  ```
